# The Haunted House

<img width="1264" height="934" alt="image (51)" src="https://github.com/user-attachments/assets/aa6993b5-bcfc-44e0-91e6-4ecbd2825a10" />
A game where you are in a haunted house and you need to avoid the monsters! <BR>
This game is my first try with raycasting technology  
Use the arrow keys to move and WASD to sidestep.  
Collect the candy to get points.  
You also get points by surviving longer.
