A game where you are in a haunted house and you need to avoid the monsters! <BR>
This game is my first try with raycasting technology, where a vertical line's rendering height inversely depends on the distance a ray has to go to hit the wall from a top-down perspective.  <BR>
Use the arrow keys to move and WASD to sidestep.  <BR>
Collect the candy to get points.  <BR>
You also get points by surviving longer.
